EcoDash: African Digital Logistics & Infrastructure Simulator

Project Description
EcoDash is an interactive 2D simulation based on delivering important supplies to rural and underserved communities in Africa.
The user will be able to control a solar-powered delivery drone deal with realistic challenges such as battery levels, the weather, obstacles, load-shedding and difficult infrustructure.

Techologies used:
1. HTML5 Canvas
2. CSS3
3. JavaScript
4. GitHub

Project Structure
index.html is the main webpage
style.css is the styling for the project
script.js is the JavaScript and functions

Run the Project
1. Download repository
2. Open project folder
3. Open index.html in a web browser
4. Simulation will run
